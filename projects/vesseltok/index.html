✦ ECCV 2026 Spotlight

VesselTok

Tokenizing Vessel-like 3D Biomedical Graph Representations for Reconstruction and Generation

Chinmay Prabhakar · Bastian Wittmann · Tamaz Amiranashvili · Paul Büschl · Ezequiel de la Rosa · Julian McGinnis · Benedikt Wiestler · Bjoern Menze · Suprosanna Shit

Read paper ↗ PDF ↗ Code ↗ Data ↗

IN ONE MINUTE

The central idea

Vascular anatomy is geometrically detailed and topologically complex. VesselTok learns a compact, tokenized representation of vessel-like 3D graphs, enabling generative modeling without reducing the problem to a small collection of branches.

METHOD

From centerlines to a generative latent space

01

Tokenize anatomy

Encode centerline points with pseudo-radius information into a learned latent token set using an implicit-function autoencoder.

02

Reconstruct structure

Decode the tokens into an occupancy representation and recover a 3D graph representation of the underlying vessel-like structure.

03

Model and complete

Learn generative priors with latent diffusion and investigate conditional completion with flow matching in the same representation space.

APPLICATIONS

What the representation enables

Across anatomies

Experiments span airway and vascular structures, including brain and lung networks.

Generative modeling

Learn distributions of realistic vessel-like geometries in a compact latent space.

Structural completion

Use learned representations in downstream tasks including link prediction and point-cloud infilling.

REPRODUCIBILITY

Explore the resources

The public repository includes the training and evaluation pipeline, while the dataset release provides preprocessed centerline data. See the repository for checkpoint setup and usage details.
